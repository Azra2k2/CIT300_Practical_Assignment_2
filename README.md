# Data Structure & Graph Performance Analyzer

**Module:** CIT300 Data Structures and Algorithms - Graded Practical Assignment 2
**Language:** Java (console application)

## Project Description
A console-based Java application that demonstrates Array, Stack, Queue, Linked List,
Searching (Linear/Binary), Graph (BFS/DFS) and a performance comparison of algorithms.
